I build developer tooling around **El Salvador's electronic invoicing system (DTE)** —
the kind of integration where a broken signature path looks healthy right up until the
day you transmit for real.

Most of my work is TypeScript on the backend: Express, Prisma, JSON Schema validation,
JWS signature verification. I care about tests that describe behavior, architecture that
tells you what the system does before it tells you how, and tools that fail loudly
instead of politely.

Construyo herramientas para desarrolladores alrededor del **sistema de facturación
electrónica de El Salvador (DTE)** — ese tipo de integración donde un camino de firma
roto se ve perfectamente sano hasta el día que transmitís de verdad.

La mayor parte de mi trabajo es TypeScript en el backend: Express, Prisma, validación
con JSON Schema, verificación de firma JWS. Me importan los tests que describen

y las herramientas que fallan fuerte en lugar de fallar en silencio.
